Two adaptations, both permitted under CC BY:

- Every `stroke="#000000"` became `stroke="currentColor"`, so an icon takes the
  colour of the text beside it.
- `search.svg` lost its enclosing ring, leaving the bare magnifier. `facebook.svg`
  came from the Colors build and lost its two flat fills, leaving the 1px outline
  underneath so it matches the weight of `instagram.svg`.

## youtube.svg

The free Ultimate Light set has no YouTube mark, so this one comes from
**Flex Line – Free** (Streamline, CC BY 4.0), the same exception already made
for `facebook.svg`. Its strokes were rewritten to `currentColor` and its
stroke width dropped from 1.7143 to 1, so it draws at the same weight as the
rest of the set beside it.
